# بوت تيليجرام - نسخة Python

## الخطوات

1. **أنشئ بوتاً جديداً على تيليجرام:**
   - افتح محادثة مع [@BotFather](https://t.me/BotFather)
   - أرسل `/newbot` واتبع التعليمات
   - احصل على التوكن (نص طويل يشبه `123456:ABC-DEF...`)

2. **ثبّت المتطلبات:**
   ```bash
   pip install -r requirements.txt
   ```

3. **ضع التوكن:**
   - الطريقة الأفضل: متغير بيئة
     ```bash
     export TELEGRAM_BOT_TOKEN="التوكن_هنا"
     ```
   - أو عدّل السطر في `bot.py`:
     ```python
     BOT_TOKEN = "التوكن_هنا"
     ```

4. **شغّل البوت:**
   ```bash
   python bot.py
   ```

5. افتح بوتك على تيليجرام وأرسل `/start`.

## الميزات الحالية
- `/start`, `/help` — ترحيب ومساعدة
- `/note <نص>` — حفظ ملاحظة
- `/notes` — عرض الملاحظات
- `/clear` — حذف الملاحظات
- رد تلقائي على أي رسالة (جاهز لربطه بنموذج ذكاء اصطناعي)

## كيف تضيف ميزات لاحقاً
- للرد بذكاء حقيقي: استبدل محتوى دالة `handle_message` باستدعاء API
  (مثل Anthropic أو OpenAI أو أي نموذج آخر).
- لإدارة مجموعات: أضف `ChatMemberHandler` لرصد انضمام/مغادرة الأعضاء.
- لقاعدة بيانات حقيقية بدل ملف JSON: استبدل `load_notes`/`save_notes`
  بـ SQLite أو PostgreSQL.
